1. 게임 개요

real 3D car는 도로 위 장애물을 피하며 점수를 쌓는 3D 레이싱 게임입니다. 플레이어는 난이도를 선택하고, 차량을 좌우로 조작하며, 직선 구간에서 등장하는 구구단 미니게임으로 추가 점수를 획득할 수 있습니다.

2. 실행 방법

  1. 프로젝트 폴더로 이동합니다: C:\work\AI\LLM\codex\3dCar
  2. 개발 서버 실행: npm run dev
  3. 브라우저에서 Vite가 안내하는 주소를 엽니다. 일반적으로 http://localhost:5173입니다.
  4. 배포용 빌드 확인은 npm run build로 실행합니다.

3. 시작 화면

게임 시작 전 난이도를 선택한 뒤 Start Game 버튼을 누르면 레이스가 시작됩니다.

표시 의미
S 직선 구간 지속 시간
C 곡선 구간 지속 시간
M 미니게임 박스가 화면에 표시되는 시간

6. 왼쪽 정보 박스

게임 중 왼쪽 상단 정보 박스에서 현재 주행 상태를 확인할 수 있습니다.

  • Speed: 현재 차량 속도
  • Score: 현재 점수
  • Distance: 주행 거리
  • Best Score: 최고 점수
  • Difficulty: 현재 선택된 난이도
  • Obstacle Speed: 장애물 기본 속도와 주행 입력에 따른 변화량

7. 점수 규칙

  • 기본 점수는 주행 시간, 주행 속도, 난이도 가중치에 따라 계속 증가합니다.
  • 빠른 속도로 운행할수록 더 높은 속도 가중치가 적용됩니다.
  • 난이도가 높을수록 더 높은 점수 배수가 적용됩니다.
  • 미니게임 정답 시 +300점이 추가됩니다.
  • 미니게임 오답 또는 시간 초과 시 -300점이 감산됩니다.
  • 점수는 0점보다 낮아지지 않습니다.

8. 구구단 미니게임

직선 구간에서 오른쪽에 구구단 미니게임 박스가 표시됩니다. 문제마다 정답 입력 대기시간은 3초입니다.

  • 초보자와 중급자는 직선 구간 시작 후 5초 뒤 미니게임이 표시됩니다.
  • 고급자와 프로는 직선 구간 시작과 동시에 미니게임이 표시됩니다.
  • 미니게임이 시작될 때 빰빠라 효과음이 재생됩니다.
  • 정답이면 좋아! 팝업과 경쾌한 효과음이 재생됩니다.
  • 오답 또는 시간 초과면 안좋아! 팝업과 짧은 낮은 효과음이 재생됩니다.
미니게임 표시 시간은 난이도별 M 값입니다. 입력 대기시간 3초와는 별도로 동작합니다.

9. 충돌과 재시작

장애물과 충돌하면 게임이 멈추고 충돌 화면이 나타납니다. 이 화면에서 난이도를 다시 선택한 뒤 Restart Race를 누르면 새 레이스가 시작됩니다.

  • 충돌 후 재시작 시 미니게임의 이전 문제나 남은 시간은 이어지지 않습니다.
  • 선택한 난이도는 왼쪽 정보 박스에 즉시 반영됩니다.
  • 최고 점수는 브라우저 로컬 저장소에 저장됩니다.

10. 차량 사진 업로드

왼쪽 정보 박스의 Upload Photo 버튼으로 이미지를 선택하면 차량 지붕에 사진이 표시됩니다. Clear 버튼을 누르면 기본 이미지로 되돌릴 수 있습니다.

11. 음악과 효과음

  • BGM On/Off 버튼으로 배경음악을 켜거나 끌 수 있습니다.
  • 충돌 시 충돌 효과음이 재생됩니다.
  • 미니게임 시작, 정답, 오답 상황에 각각 효과음이 재생됩니다.

12. 문제 해결

증상 확인 방법
게임 화면이 보이지 않음 개발 서버가 실행 중인지 확인하고 브라우저 새로고침을 합니다.
모바일 좌우 버튼이 보이지 않음 브라우저 캐시를 비우고 화면 폭이 모바일 크기인지 확인합니다.
효과음이 들리지 않음 브라우저 탭 음소거, OS 볼륨, 첫 사용자 클릭 이후 재생 여부를 확인합니다.
미니게임이 나타나지 않음 현재 도로가 직선 구간인지 확인합니다. 초보자/중급자는 직선 시작 후 5초 뒤 표시됩니다.
